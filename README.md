# Calculadora ET403 Pro

Herramienta web interactiva que combina una calculadora digital avanzada con conversores de unidades de longitud y peso.

## Características
- **Calculadora digital:** Operaciones aritméticas básicas, manejo de porcentajes y cambio de signos (`+/-`).
- **Conversor de Longitud:** Conversión bidireccional entre Metros (m) y Centímetros (cm).
- **Conversor de Peso:** Conversión bidireccional entre Kilogramos (kg) y Gramos (g).
- **Validaciones:** Control de campos vacíos y rechazo de valores numéricos negativos.
- **Diseño:** Interfaz moderna con paleta de colores corporativa (Azul `#2563EB`, Verde `#15803D` y Violeta `#9333EA`).

## Tecnologías usadas
- HTML5
- CSS3 (Variables, Grid, Flexbox, Gradientes)
- JavaScript (ES6)
